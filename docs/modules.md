# Modules

The 2 modules of **go-docutils**. Each links to its source and to
its generated API reference.

| Module | What it is | Reference |
| --- | --- | --- |
| [`docutils`](https://github.com/go-docutils/docutils) | the engine: a reST parser matching the reference on both of its corpora, the doctree, and HTML and LaTeX writers | [pkg.go.dev](https://pkg.go.dev/github.com/go-docutils/docutils) |
| [`autodoc`](https://github.com/go-docutils/autodoc) | the other direction: a Go package's own API documentation rendered AS reST, to feed the engine | [pkg.go.dev](https://pkg.go.dev/github.com/go-docutils/autodoc) |

A one-line summary each, and nothing more: what the parser does with a construct,
and what it deliberately does not implement, lives in that repository's README beside
the measurement that decided it.
